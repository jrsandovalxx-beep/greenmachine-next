# GMF-009 — Matchups grid: L30 vs the starter's mix, season toggle, grade stays L30 (D-079, D-081, D-089…D-091)

**Status**: completed 2026-08-22. Submission 1 via PR #46 (merge commit
`de86d97`, base `staging`); the PO's review corrections landed as the
D-090/D-091 split via PR #47 (merge commit `5d099b9`).

## Delivered

- `greenmachine.live.pipeline` — `BatterGridLine`: one grid row per batter
  computed over his last 30 days against the opposing starter's qualifying
  (14%, D-079) mix pitches from the starter's side — AB/H/BIP, barrels, HR,
  EV, Barrel/PA %, Hard-Hit %, AVG, SLG, ISO, +350 ft %, Pull Air %, xwOBA,
  Swing-Str %; batted-ball denominators follow the source's contact
  classification. The mix's D-081 reach chain: L30 → L45 (the extra days
  fetched only when a starter has zero L30 pitches) → season board → last
  season, with the window used named on the surface. `PitchMixRow` /
  `BatterPitchLine` rewire the grade to the same L30 inputs at
  `MIX_USAGE_SHARE` 0.14; league baselines stay season-long. The season
  view composes from the hitting line (SLG via the new `total_bases`), the
  statcast board, and the arsenal board; +350 ft % and Pull Air % have no
  season source and name the absence. `PitchEvent.hit_distance`
  (`hit_distance_sc`) feeds the distance column and the EV log.
- `streamlit_app.py` — the reworked Matchups grid (the D-079 columns plus
  identity, form, and grade cells), the tab-level season-view toggle with
  the grade always the L30 computation, per-lineup scope captions naming
  the mix window, and the EV event log's new Dist column (D-091).
- D-089 logs the derivation definitions (L45 trigger = zero L30 pitches;
  season-view source composition); D-090 splits +350 ft % from Pull Air %;
  D-091 adds the EV-log distance.
