# GMF-006 — Live Slate Board with Grading v1

**Status**: completed 2026-08-21 via PR #30 (merge commit
`f2e29db2c84265734d1e5a5e937e81a569d47df3`, base `staging`).

## Delivered

- `greenmachine.live.transport` — the second permitted network module:
  two-host allowlist (`statsapi.mlb.com`, `baseballsavant.mlb.com`), HTTPS
  only, redirect targets re-validated before following, bounded timeout and
  one retry on transient statuses (D-069).
- `greenmachine.live.mlb_api` — Stats API adapter: slate with venues and
  probable pitchers, posted batting orders, season hitting/pitching lines
  with bat side and throwing hand. Every failure surfaces as a typed
  `FetchFailure` with a plain-language reason.
- `greenmachine.live.savant` — Savant CSV adapter: Statcast quality-of-contact
  board, expected statistics, bat-tracking (date-windowed), batted-ball
  profile, pitch-arsenal boards (both kinds), and the per-pitch day search.
  Percent columns normalized to fractions at the boundary; BOM-safe;
  row-tolerant against tiny-sample empties (D-073(g)).
- `greenmachine.live.form` — per-pitch event aggregation (D-068 definitions)
  and the per-metric L7→L14 window resolution with per-metric floors.
- `greenmachine.live.grading` — one observation state per configured
  component (never zero-filled, never guessed), `freeze_input_snapshot` →
  `score_snapshot` under the RECENT_7D profile; matchup derivations per
  D-073(a).
- `config/production/gm_hr_v1.yaml` — the D-071 provisional production
  grading configuration (12 points, 3/3/2/2/2, cutoffs 4/6/8/10), the one
  approved production YAML (architecture-test enforced).
- `greenmachine.live.pipeline` — `build_board`: slate → lineups (posted, or
  labelled estimates) → season boards → form windows → park factors →
  conditions → graded `BatterCard`s; every degraded source is a named
  absence plus a diagnostics line, never a fatal error.
- `streamlit_app.py` — the four D-072 tabs (Sluggers / Arms / Matchups /
  Conditions) under "Today's slate"; highlight thresholds read from the
  loaded config; the board is cached so a rerun is not a refetch; the live
  path binds only outside the `local` environment, mirroring the weather
  seam.
- `ProviderId` extended with `mlb_stats_api` and `nws` (D-070); glossary
  and enum tests updated.
