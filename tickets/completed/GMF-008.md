# GMF-008 — Matchup popup: per-pitch tables, Arsenal, adjustable threshold (D-080, D-086…D-088)

**Status**: completed 2026-08-21. Submission 1 via PR #43; the PO's
corrections landed as the D-087/D-088 rework via PR #44; the D-075 dialog
guard hardening via PR #45 (base `staging` throughout).

## Delivered

- `greenmachine.live.pipeline` — `PitchLine` per-pitch aggregation with
  per-scope denominators (usage over scope pitches, AVG/SLG over at-bats,
  barrel/hard-hit over batted balls, whiff over swings, xwOBA over PA-ending
  rows); the batter's matchup scope = his L30 events against the opposing
  starter's side (D-088) over a 31-day window fetched with a keep-filter so
  memory stays flat (342 MB measured); `PitcherCard.season_lines` = the
  season-long arsenal with a lazy last-season fallback fetched only for
  probables with no current record (D-087).
- `streamlit_app.py` — the batter detail dialog: matchup per-pitch table
  with qualifying-mix toggle, the renamed **Arsenal** table (season figures;
  side filter reading the recent record, numbers staying season-long), the
  exit-velocity log, and one in-popup usage-threshold slider (5–40%)
  driving all three displays — display-only against grading's ratified 15%
  (D-070). Three usage states survive both toggle positions; absent scopes
  and absent counts are named, never zero-filled.
- D-075 extended: the detail dialog call sits inside the tab guard, so a
  dialog failure degrades to a warning instead of blanking the board.
